# 固定提示、十轮重新进化

从 PICTURE 原版开始，不导入上一实验的候选、成绩历史或诊断轨迹。以同一条固定搜索指导作为每一轮的预先设计先验，允许原句索引校验；这检验给定先验后能否自动学出并选择有效插件。第 1 轮起动态输入只包括本次父版代码、程序抽样的开发轨迹、本次历史选型统计及上轮修复/退步配对样例。每轮新开 Terra CLI 会话，以一个候选计一轮，共十轮。外层固定 200 段进化、169 段测试。内层开发 665 题、选型 150 题，按同一选项顺序配对。晋级需 All 增且 False Belief 不降；两者相等时才以调用和 tokens 分胜负。冻结后用四个种子测试 700 题并报告 1515 题全集。沿用已知的 PI​​CTURE 基线与以往测试划分，属于同一基准的重跑。中途只读取运行状态；传输故障可按原协议续跑，禁止新增方向性指导或改变筛选规则。脚本及预设在启动前留存逐字快照。
